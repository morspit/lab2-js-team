# Лабораторная работа №2: Анализ успеваемости

## Цель
Отработка навыков работы с Git, ветками и командной разработкой.

## Структура проекта
- `data.js` - общие данные
- `average.js` - функция расчета среднего балла (Денис)
- `topStudent.js` - поиск лучшего студента (Анна)
- `failedStudents.js` - поиск должников (Даша)
- `letterGrades.js` - буквенные оценки (Студент_X)
- `report.js` - итоговый запуск (Макар)

## Как запустить
1. Клонировать репозиторий
2. Установить Node.js
3. Запустить: node report.js
